# iumrah — полный каталог прямых рейсов на главной, 25.11.2026

- Накопительное обновление: предыдущие Personal Dashboard, Friends motion, Personal Guide сохранены.
- Главная: существующий поиск и активная поездка → Balance (если авторизован) → «Прямые рейсы» → остальные существующие разделы. Для гостя после поиска (и активной поездки, если есть доступ) без пустой карточки баланса. Хейдер не изменён относительно предыдущего патча.
- Источник: `/api/package/storefront/flights?origin=TAS&all=1`. Параметр origin нужен только старому расчёту baseline; результат глобальный. В новом режиме сервер не ограничивает 300 публикациями и не ограничивает горизонт дат; применяет прежние правила публичности и будущих вылетов. Включаются все города, направления, классы и оба сегмента парных публикаций. Черновики, прошедшие и невалидные/непрямые варианты исключаются серверной логикой. Никаких подставных рейсов и live-поиска в карусели.
- «Все рейсы» открывает полноценный каталог из того же состояния. Карточка открывает действующий premium flight detail; выбор совместимых рейсов остаётся связан с текущей поездкой. Для несовместимых предлагается настроить маршрут. Не меняются даты/маршрут при простом просмотре. Оригинальный маршрутный каталог в конфигураторах не изменён.
- LazyHStack, LazyVStack; объединение запросов, TTL 5 минут, обновление pull-to-refresh, обработка ошибок, признак `catalogComplete` для старых версий backend. Если сервер ещё старый, приложение явно предупреждает о неполном каталоге. Цена в другой валюте не выдаётся за USD.
- Сначала установить новый накопительный Business ZIP и развернуть единый backend, затем установить накопительный iOS ZIP и собрать TestFlight. Без изменений workflow, signing, Bundle ID и схемы БД.
- Проверка: backend TypeScript + 142 runtime теста package-engine, включая 2 новых; клиентский smoke компилирует реальную функцию преобразования с DTO и проверяет 354 уникальных сегмента, разные аэропорты, классы, парные ID, отсутствие фиктивной цены и старый ответ. Smoke общего баланса также успешен. Swift syntax parse всех изменённых Swift-файлов. Xcode/iOS SDK и доступ к production отсутствуют: полноценная сборка, UI и фактический опубликованный каталог production не проверены.
