# Booking Experience 3.0 — Foundation 1A merged

This cumulative overlay supersedes Foundation 1A (unmerged). Based on the supplied UI Final and Sales Offers overlays, plus the original lattice-mobile snapshot. Preserves the existing Sales Offers D1 table and IDs, all previous UI files, staff CRUD/revisions/view tracking/notifications, and legacy fragment URLs. Adds native client adapter, verified-contact acceptance with revision and idempotency, a new auxiliary acceptance table, SMS and initial APNs integration, and browser OTP/footer. Existing links remain valid, with AASA and native URL support; actual Apple domain association and provider delivery require deployment and device testing. The old public accept endpoint is retained for backward compatibility; the updated browser and iOS use verified acceptance. Foundation 1B is not implemented. Do not deploy over an environment that already has the incompatible unmerged Foundation offer schema without a migration audit. Workflows unchanged. Original release manifests describe historical overlays; this manifest describes the merged overlay.

Checks: backend 140/140, package engine 118/118, TypeScript and Swift syntax; no Xcode archive or live deployment performed. Native contact integration is tested with a simulated proof DB, not live SMS/email providers.
