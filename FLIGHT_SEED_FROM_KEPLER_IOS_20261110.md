# iumrah Flight Hub — импорт опубликованных рейсов из kepler-ios

Источник: `iumrah-active-flights-from-kepler-ios.zip`, дата экспорта 2026-11-10. Содержит только публичные идентификаторы рейсов, без исторических цен, документов, пользователей и отелей.

- 79 рейсов в файле: C6 — 28, HY — 18, XY — 33.
- На запуске `seed` сохраняются только ещё не вылетевшие рейсы в пределах 30 дней по Ташкенту. Поэтому итоговое количество может уменьшаться со временем.
- Повторный импорт не создаёт дубликаты, так как Flight Hub использует стабильный `flight_key`.
- Цены останутся пустыми до реальной успешной проверки в источнике. Автоматизацию сайтов авиакомпаний отдельно проверяем в логах `monitor`.

## Запуск без новых workflow и Secrets

1. В `lattice-mobile` загрузи в корень `iumrah-business-update.zip` и примени штатным ZIP-установщиком.
2. В существующем `Provision new Cloudflare Flight Hub` выбери `action=seed`.
3. Обнови мониторинг в iumrah Business. Должны появиться рейсы, но пока без подтверждённых цен.
4. Выбери `action=monitor`, проверь логи Centrum Air, Uzbekistan Airways и Flynas.

Для этого импорта **не нужны** `OLD_CLOUDFLARE_*` и `FLIGHT_SYNC_FEED_URL`: локальный файл всегда имеет приоритет. Если файл убрать, старые пути импорта сохраняются. Нет доступа к реальному Cloudflare в этой среде, поэтому онлайн-результат подтвердит GitHub Actions.
